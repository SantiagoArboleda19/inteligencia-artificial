Ejercicios de Inteligencia Artificial
Este repositorio contiene los tres ejercicios realizados durante las sesiones de IA.

Ejercicio 1 – Algoritmo
Algoritmo que ordena tres números de menor a mayor, incluyendo números iguales.

Ejercicio 2 – Archivo descargable
Archivo generado durante la actividad práctica de la sesión.

Ejercicio 3 – Página web con IA
Página web creada con ayuda de una herramienta de Inteligencia Artificial.

Organización
Cada ejercicio está guardado en su respectiva carpeta.
